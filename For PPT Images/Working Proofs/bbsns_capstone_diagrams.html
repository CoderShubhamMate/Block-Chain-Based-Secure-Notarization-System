9. KYC Face Mesh Verification Flow

Maps out the step-by-step identity matching workflow that runs during notary onboarding to prevent credential theft.

graph TD
    Start["Applicant Starts Identity Check"] --> Input["Input Personal Credentials (National ID, Email)"]
    Input --> Webcam["Initialize Secure Client Webcam Stream"]
    Webcam --> FaceCapture["Capture Face Frame Target"]
    FaceCapture --> FaceMesh["Extract Facial Landmarks (FaceMesh)"]
    FaceMesh --> Descriptor["Generate 128-dimensional Face Vector"]
    
    subgraph "Spring Boot Server Processing"
        VectorCheck["Validate Descriptor Distance vs DB Store"]
        DbMatch{Existing Face Registered?}
    end

    Descriptor --> VectorCheck
    VectorCheck --> DbMatch
    DbMatch -->|"Yes (Similarity > 0.6)"| RejectKYC["Reject: Identity Already Claimed"]
    DbMatch -->|"No Match (Unique Face)"| VerifyID["Verify National ID via Govt Database"]
    
    VerifyID --> IDCheck{Valid National ID?}
    IDCheck -->|No| RejectKYC
    IDCheck -->|Yes| CreateProfile["Issue Verified Onboarding Token"]
    CreateProfile --> Complete["Notary Application moves to KYC_VERIFIED Status"]

11. User Registration Flow

Step-by-step logic path for onboarding new clients into the system.

flowchart TD
    A[Start Registration] --> B[Enter Email and Password]
    B --> C[Validate Password Strength]
    C -->|Weak| D[Display Error: Weak Credentials]
    D --> B
    C -->|Strong| E[Input National Identification Number]
    E --> F[Normalize National ID: Trim/Spaces/Uppercase]
    F --> G[Connect Wallet Address]
    G --> H[Check Unique Email, Wallet, & ID Hash in DB]
    H -->|Conflict| I[Display Registration Error: Duplicate User]
    I --> B
    H -->|Unique| J[Create User Record: role='user', identity_state='ACTIVE']
    J --> K[Complete: Direct Routing to Dashboard]

12. Login + Wallet Signing Flow

Operational control chart representing how the login guard behaves at runtime.

flowchart TD
    A[Start Login] --> B[Input Email, Password, & ID]
    B --> C[Prompt Wallet Sign Request]
    C -->|User Rejects| D[Abort Authentication]
    C -->|User Confirms| E[Recover Address from Cryptographic Signature]
    E --> F[Check if User Registered in Database]
    F -->|No Profile| G[Provision Admin if wallet matches On-chain Admin]
    F -->|Found| H[Verify Password & National ID matches Hash]
    H -->|Mismatch| I[Fail: 401 Invalid Credentials]
    H -->|Match| J[Verify liveRole and isBanned status on BNB Chain]
    J -->|Banned| K[Fail: 403 Suspended]
    J -->|Active| L{identity_state == 'ACTIVE'?}
    L -->|No| M[Fail: 403 Account Verification Required]
    L -->|Yes| N[Generate 12-Hour JWT & Allow Dashboard View]
